# Web 원본 대비 차이

기준은 `docs/design/README.md`와 `screens-a/b/c.md`다. 수정 전 웹은 거의 CSS가 없어 브라우저 기본 모양(기본 버튼·시스템 글꼴·이모지 아이콘)이었다. 기능, testID, 문구, ViewModel, 분석 이벤트는 바꾸지 않았다.

처리 표기: 맞춤 / 관례 유지(웹이라 다르게 둠) / 보류(이유).

## 공통 토대

| 항목 | 원본 기준 | 수정 전 | 처리 |
| --- | --- | --- | --- |
| 색·간격·라운드 토큰 | README §2, `shared/design/tokens.json` | 하드코딩 색(`#666`, `#f2f2f2` 등) | 맞춤. `npm run gen:design`이 `tokens.css`와 `tokens.ts`를 생성하고 `generate.test.ts`가 JSON과의 일치를 검사한다 |
| 글꼴 | README §3 | 시스템 글꼴 | 맞춤. 번들 글꼴을 woff2로 변환해 `@font-face`로 로드한다(`npm run gen:fonts`) |
| 아이콘 | `shared/design/icons` 44개 | 이모지·문자(‹ › ✕) | 맞춤. 인라인 SVG 컴포넌트로 생성하며 `currentColor`로 색을 입힌다 |
| 테마 | 라이트 고정 | 브라우저 기본 | 맞춤. 앱 루트에 배경·글색 적용, `color-scheme: light` |
| 모바일 컬럼 | 모바일 폭 | 전체 폭 | 맞춤. 430px 중앙 컬럼, 고정 요소는 `--column-inset` 기준 |
| 모션 | 원본 애니메이션 | 없음 | 맞춤. 쉬머·시트·눌림을 넣고 `prefers-reduced-motion`에서는 모두 끈다 |
| 버튼(§1.1~1.2) | 높이·라운드 12·눌림·비활성 12% | 기본 버튼 | 맞춤 (`Button`) |
| 체크박스·로고·스켈레톤·토스트·다이얼로그·시트·빈/오류 상태 | screens-a §1, screens-c §1 | 기본 요소 | 맞춤 (`Checkbox`, `Logo`, `Skeleton`, `ToastHost`, `ConfirmDialog`/`AlertDialog`, `Sheet`, `StateViews`) |
| 상단 바·뒤로 버튼 | screens-c 상단 바 | 텍스트 버튼 | 맞춤 (`TopBar`, `BackButton`, `CloseButton`) |

## 남은 차이·보류

| 항목 | 이유 |
| --- | --- |
| 네이티브 시트의 드래그 닫기·스프링 | 웹은 바깥 터치·Esc·닫기 버튼으로 닫는다(관례 유지) |
| 하단 바 블러·햅틱 | 웹에 해당 없음 |
| 업로드 앨범/카메라 버튼의 글자 라벨 | 문구 파일에 없는 문구를 만들지 않으려고 아이콘만 둠(접근성 이름은 기존 유지) |
| 기록 달력의 책자(스택) 애니메이션 | 웹 기록은 달력 격자 구조라 해당 연출을 두지 않음(관례 유지) |
| 시스템 폰트 크기 연동 | 웹은 브라우저 확대로 대응 |
