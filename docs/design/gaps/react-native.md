# React Native 원본 대비 차이

기준은 `docs/design/README.md`와 `screens-a/b/c.md`다. 처리 열: **맞춤**(원본 수치로 맞춤), **관례 유지**(플랫폼 관례에 맞춰 다르게 둠), **보류**(이유와 함께 남김). 화면 확인은 코드 대조로만 했고 스크린샷 대조는 팀장 검수 단계에서 한다.
