# 열린 질문

규칙이 없거나 서버 동작이 불명확해서 이 레포가 임시로 정해 둔 것, 또는 확인이 필요한 것. 구현은 "임시 동작"대로 하고, 답이 나오면 [decisions.md](decisions.md)로 옮긴다. 근거는 [api-contract §8.2](../reference/api-contract.md).

| ID | 질문 | 임시 동작 | 영향 플랫폼 |
| --- | --- | --- | --- |
| Q-01 | 웹 클라이언트 CORS 허용 오리진이 개발 서버에 있는가 | 웹은 개발 중 로컬 프록시(Vite dev proxy)로 API를 부른다. 배포 웹은 미정 | Web |
| Q-02 | 카카오 JS SDK(웹)에서 OIDC `idToken` + nonce를 받을 수 있는가. 리다이렉트 방식에서 rawNonce 보관 위치 | 웹 카카오 로그인은 별도 PR에서 검증. 막히면 웹은 게스트 + 개발용 로그인 우회(개발 빌드 한정)로 나머지 기능을 먼저 만든다 | Web, RN(Expo Go 불가 시) |
| Q-03 | 웹 토큰 보관(쿠키 미지원 서버에서 refresh token을 어디에 둘지) | access는 메모리, refresh는 `localStorage` 금지 원칙을 깨고 임시로 IndexedDB에 보관하되 위험을 README에 명시 | Web |
| Q-04 | 웹 푸시(FCM Web) 서버 지원 여부 | 웹은 푸시 수신·기기 등록을 하지 않는다. 알림함은 동일하게 제공 | Web |
| Q-05 | 탈퇴 시 카카오 연결 해제(unlink) 필요 여부 | 하지 않는다(D-16) | 전체 |
| Q-06 | 개발 서버 토큰 수명 실제 값 | 응답의 `expiresIn`, `refreshTokenExpiresIn`만 쓴다. 테스트는 fixture 값으로 | 전체 |
| Q-07 | refresh 응답 유실 시 복구(서버 유예 없음) | 재로그인으로 처리 | 전체 |
| Q-08 | 이미지 처리 실패(VALIDATING→REJECTED)가 알림으로 오지 않음 | 홈 히어로가 Empty로 돌아가는 것으로만 알 수 있다(D-06) | 전체 |
| Q-09 | 정지 회원에게 로그인 직후 안내가 필요한가 | 안내하지 않고 403을 받는 곳에서 안내(D-08) | 전체 |
| Q-10 | 게시물 이미지 해상도 상한(`TOO_MANY_PIXELS`) 수치 | 긴 변 4096으로 줄여 보내므로 사실상 해당 없음 | 전체 |
| Q-11 | 알림함에 `TOPIC`·`REMINDER` type이 올 수 있는가(규칙은 없다, enum은 있다) | 오면 목록에 표시하고 탭하면 홈으로 이동 | 전체 |
| Q-12 | 로그아웃 상태 푸시 탭 후 로그인하면 목적지로 복귀할지 | 버린다(D-11) | 모바일 4종 |
| Q-13 | 앱 버전 전송 경로(피드백에 앱 버전 기록) | 보내지 않는다 | 전체 |
| Q-14 | 429·Retry-After 사용 여부 | 오면 존중(D-21) | 전체 |
| Q-15 | 카카오 개발자 콘솔의 플랫폼 등록(번들 ID·패키지명·키 해시·웹 도메인)이 새 앱 식별자를 허용하는가 | 기존 앱과 같은 번들 ID·패키지명(`com.stonefive.chalkak`)을 쓰면 시뮬레이터·에뮬레이터 로그인이 된다. Flutter·RN도 같은 식별자로 빌드한다(동시 설치 불가는 감수) | 모바일 4종 |
| Q-16 | Firebase 설정 파일을 새 앱에서 쓸 수 있는가 | 같은 식별자면 기존 설정 파일 재사용(레포에 커밋하지 않음). 없으면 푸시·분석을 끈 빌드로 진행 | 모바일 4종 |

## 기능 문서에 남은 세부 쟁점

아래 Q-보다 작은 세부 쟁점은 각 문서 끝의 "확인 필요"(명세)·"구현 시 확인할 쟁점"(카탈로그) 절과 카탈로그의 `[결정 필요]` 표시에 임시 동작과 함께 있다. 구현 스레드는 해당 영역 작업 전에 그 절을 읽고, 임시 동작을 바꾸게 되면 decisions.md에 D-로 올린다.

- 명세: [features/](features/) 11개 파일의 `## 확인 필요`
- 테스트: [../testing/catalog/](../testing/catalog/) 11개 파일의 쟁점 절과 `[결정 필요]` TC
