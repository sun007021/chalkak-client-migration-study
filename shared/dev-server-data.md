# 개발 서버 E2E 데이터

다섯 클라이언트가 개발 서버(`https://chalkak-dev.pysun.kr`)에 붙여 E2E를 돌릴 때 기대할 수 있는 데이터. 2026-10-28 KST 조사·생성 기준이다. 서버 데이터는 계속 바뀌므로 숫자는 시작점으로만 보고, 테스트는 개수를 고정값으로 단언하지 않는다.

계정·비밀번호·키는 여기에 쓰지 않는다. 사용자에게 받은 값을 로컬에서만 쓴다.

## 1. 이번에 만든 것

| 종류 | ID | 내용 |
| --- | --- | --- |
| 주제 | `01a18246-e6c9-70e2-9715-62af1ee778b9` | "가을 하늘", topicDate `2026-10-28`, 20:33~23:59 KST (`11:33Z`~`14:59Z`), 처음 게시물 0개 |

관리자 API로 만들었다. 다른 생성·수정·삭제는 하지 않았다.

- 이 주제는 2026-10-28 23:59 KST에 닫힌다. 그 뒤 날짜에 오늘 주제가 필요하면 관리자 웹에서 그날 주제를 새로 만든다. 관리자 API는 공개 전(`BEFORE_OPEN`) 주제만 만들 수 있다(시작 시각의 KST 날짜가 topicDate와 같아야 하고, 참여 기간이 겹치면 안 된다).
- 과거 날짜 주제, 회원, 게시물, 좋아요, 알림은 관리자 API로 만들 수 없다. DB 직접 삽입이 필요하다(아래 4절).

## 2. 계정

| 계정 | userId | 상태 |
| --- | --- | --- |
| 카카오 테스트 계정(추정: 2026-10-28 20:13 KST 가입한 가장 최근 KAKAO 회원) | `01a18236-aeaa-79b0-9280-91c6667976e5` | 게시물 0개, 알림 0개 |

전체 회원 49명(ACTIVE 49, KAKAO 4·GOOGLE 15·APPLE 1·소셜 없음 29).

## 4. 아직 없는 것

다른 회원이 많은 오늘 게시물, 좋아요가 많은 게시물, 테스트 계정의 과거 기록(이번 달·지난달), 알림 2페이지 분량은 DB에 직접 넣어야 만들 수 있다. EC2 SSH가 허용된 네트워크에서만 가능하다. 넣게 되면 이 문서를 갱신한다.
